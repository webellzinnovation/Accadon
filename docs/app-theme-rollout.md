# App theme rollout

`app-theme.css` is the shared application role contract. Legacy layout CSS now references these roles rather than competing palettes. Purple anchors navigation, dark hero panels and headings. Orange is the one energy accent across an application view. The standalone kit retains its four preview modes. Academy custom-brand previews retain their own chosen color without changing the locked Accadon logo.

Quiet card, form and data surfaces use translucent lavender with opaque readable fallback. Actions use dark ink on orange (7.09:1); active navigation uses white on purple (6.91:1). Green qualification/wins and red losses remain semantic, never decorative lime. Inputs share a 12px corner rule; cards use 20px, detail dialogs 24px and action pills are fully rounded.

`AppDialog` provides a native focus-trapped modal with Escape, backdrop dismissal and focus return. Secondary event previews and match notes use it instead of expanding the page. Existing native match-centre dialogs share the frosted appearance. `AppDateInput` retains editable native ISO date values and standard field labels, with a shared vector calendar popup and min/max date limits. Supported Chromium uses a themed base-select picker; browsers without base-select retain their native accessible picker with themed field/option colors. Scrollbars are themed globally and internally; system settings may still control native scrollbar visibility.

Glyph-only decorative/action hosts use shared KitIcon vectors. Avatars, ranks and numeric labels remain text. The canonical supplied Accadon mark is unchanged. No authentication, delivery, publication, payment, map lookup or persistent workflow has been enabled by this visual migration. Demo/reset/empty-state wording is preserved.
